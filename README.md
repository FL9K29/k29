# Гоша не спит — генератор коротких мультиков

Вертикальные ролики 1080×1920, 24 fps, ~40–45 секунд: карточка-хук, плашки «ПРАВИЛО №N»,
русские субтитры, музыка и звуковые эффекты (всё синтезируется кодом, без сторонних сэмплов).

## Запуск

```
pip install skia-python numpy      # плюс системные ffmpeg и libegl1
python3 make.py render             # все ролики -> output/<id>/
python3 make.py render RU12 RU13   # только выбранные
python3 make.py sheet RU6          # раскадровка для быстрой проверки -> /tmp/sheets
python3 make.py channel            # аватар и описание канала -> output/channel/
```

Для каждого ролика создаются:

- `<id>_SUBS_RU.mp4` — с вшитыми субтитрами;
- `<id>_CLEAN.mp4` — без субтитров (хук и плашки правил остаются);
- `<id>_subtitles_RU.srt`, `<id>_script_RU.txt` — субтитры и сценарий;
- `<id>_caption_RU.txt` — текст под видео с хэштегами.

## Как устроено

- `stories.py` — сценарии. Сцена = фон + персонажи + реплики; `*слово*` красит слово в красный, `_слово_` в жёлтый.
- `engine.py` — отрисовка персонажей, фонов, чата, титров и раскладка по времени.
- `audio.py` — музыка по настроению сцены (`comedy`, `spooky`, `warm`) и эффекты.

Шрифт Montserrat распространяется по лицензии SIL OFL (`assets/fonts/OFL.txt`).
